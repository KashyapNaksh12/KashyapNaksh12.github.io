# Nitin Kashyap — GitHub Pages Portfolio

1. Create a public GitHub repository named `KashyapNaksh12.github.io`.
2. Upload `index.html` to its root.
3. Upload your actual resume as `resume.pdf` to enable the resume button.
4. Open Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. Visit https://kashyapnaksh12.github.io/ after GitHub Pages finishes deploying.

Edit `index.html` to customize the text and links. Do not publish confidential employer/client information.
